<h1>Kanban Board</h1>

A responsive Kanban Board application built using HTML5, CSS3, and Vanilla JavaScript. The application helps users organize tasks across different workflow stages with drag-and-drop interface and persistent data storage using the browser's Local Storage.

This project demonstrates core JavaScript concepts including DOM manipulation, drag-and-drop events, local storage, and dynamic UI updates.

Features:

- Add and delete task
- Drag and drop tasks between columns
- Live task count for each column
  - To-do
  - In-progress
  - Done
- Persistent task storage using Local Storage
- Responsive user interface

Tech Stack:

1. Frontend
- Javascript(ES6+)
- HTML5
- CSS

2. Browser APIs
- HTML5 Drag and Drop API
- Local Storage API

Concepts Demonstrated:

- DOM Manipulation
- Manual State Management without frameworks
- Event Handling
- Local Storage
- Responsive Layout Design
